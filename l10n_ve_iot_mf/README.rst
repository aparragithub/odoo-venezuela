Venezuela - IoT / Máquina Fiscal
========================================================

Implementación de DLLs de The Factory HKA (VE) y desarrollos PnP para
Internet of Things (IoT) y compatibilidad con Odoo. Proporciona la
integración con máquinas fiscales vía Web Serial API (impresión desde
Facturación/Contabilidad).

Este módulo migró de IoT Box a Web Serial API en esta versión. Ver
``MIGRATION_README.md`` en la raíz del repositorio para el detalle completo
de la migración desde ``odoo-venezuela-17`` (rama ``feature/pos-mf-web-serial-api``).
