===============================================
Venezuela - Máquina Fiscal (Base Web Serial)
===============================================

.. |badge1| image:: https://img.shields.io/badge/licence-LGPL--3-blue.png

Driver base Web Serial API para impresoras fiscales The Factory HKA (TFHKA).
Proporciona la capa de conexión serial y protocolos de comunicación fiscal
compartidos entre los módulos POS y backend.

Este módulo es la migración a Odoo 19 de ``l10n_ve_mf_base`` v17.0.1.0.0,
originalmente desarrollado en el repositorio ``odoo-venezuela``, rama
``feature/pos-mf-web-serial-api`` (Odoo 17). Ver ``MIGRATION_README.md``
en la raíz del repositorio para el detalle completo de la migración.
